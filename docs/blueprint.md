# **App Name**: Kinerja Insights

## Core Features:

- Dashboard Overview: Presents a summary of KPI data including average scores and performance status, filtered by employee, position, and department.
- Employee Directory: Displays employee data. Data can be added and modified through import/export of Excel spreadsheets.
- AI KPI Suggestion Tool: Suggests relevant KPI indicators based on job title and department using generative AI.
- Automated KPI Score Calculation: Calculates KPI scores automatically after admin inputs achievements per indicator.
- Report Generation: Generates reports based on selected periods, departments, and positions, including summary averages and detailed employee achievements.
- Data Export: KPI data and reports can be exported in both Excel and PDF format.
- Multi-User Authentication: Allows admin access and also provides a user role, which allows employees to see dashboard and personal reports.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to evoke trust and professionalism.
- Background color: Light blue (#E8EAF6), a desaturated version of the primary color, to provide a calm backdrop.
- Accent color: Violet (#9575CD) for highlighting important UI elements.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines and 'Inter' (sans-serif) for body text.
- Consistent use of simple, professional icons for categories and actions.
- Clean, structured layout with clear navigation to improve user experience.
- Subtle transitions and animations on data updates to provide user feedback.
